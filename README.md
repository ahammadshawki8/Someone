# Someone

**Be the someone.**

When someone collapses, most people freeze. Someone is a Snap SPECS Lens that guides you through CPR, hands-free, one calm step at a time, with 911 seeing what you see.

Built for the Devpost "Learn AR with SPECS" hackathon. Planned with the Devpost Learn `plan-lens` skill, built by a coding agent through CLAD and the Lens Studio MCP, tested with LEAF.

> Work in progress. Full description, demo video and build notes will be added before submission.

## Disclaimer

Someone is a design concept and practice tool, not a medical device. It follows published adult hands-only CPR guidance (100 to 120 compressions per minute). In a real emergency, call your local emergency number.
